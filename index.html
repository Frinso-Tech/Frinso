MQTT Configuration

WebSocket MQTT Setup & IMEI Integration

This UI requires WebSocket MQTT support. Most brokers support this:

  • Mosquitto: Enable WebSocket listener on port 9001
  • HiveMQ: Built-in WebSocket support
  • EMQX: WebSocket enabled by default

IMEI Integration: The gateway automatically appends the device IMEI to all topics. If you know your device's IMEI, enter it above. Otherwise, the UI will auto-detect it from incoming messages.

Git-Based System Updates

About Git-Based Updates

This system allows you to remotely update the gateway software using Git. You can:

  • Update to Latest: Pull the most recent code from a specific branch
  • Update to Version: Install a specific tagged release (e.g., v1.2.0)
  • Update to Commit: Roll back or forward to any specific commit
  • Query Information: Check current version and commit details

⚠️ Important: All update operations will restart the gateway application automatically.
